# Skelettkod för P02

Skelettkod med färdig filstruktur samt riktiga drivers för ATmega328p.

**OBS!** De tillhandahållna driver-implementationerna ska inte skrivas om från grunden. Mindre justeringar (t.ex. metodnamn eller signaturer) är tillåtna vid behov för att anpassa dem till era interfaces. Uppgiften är att implementera interfaces, stubbar och systemlogik ovanpå denna struktur.

Lägg till filer för systemlogik efter behov.
